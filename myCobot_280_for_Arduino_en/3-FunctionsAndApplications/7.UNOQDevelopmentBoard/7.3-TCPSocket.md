# 7.3 TCP Socket Remote Control

TCP Socket mode is used when the Python program runs on a PC and controls the robot through UNO Q over the local network.

## Prerequisites on the PC

Install Python and `pymycobot` on the PC:

```bash
python --version
python -m pip install pymycobot
```

If a project wheel is provided, install that wheel instead of downloading a different version.

## Prerequisites on UNO Q

- UNO Q and the PC are on the same trusted LAN.
- The UNO Q socket service is running.
- The service listens on port `9000`.
- The robot is powered on and connected through UNO Q Bridge.

Check the UNO Q IP address in the system network settings or by running `ip addr` in the UNO Q terminal.

## PC Client Example

Start with a read-only command:

```python
from pymycobot import MyCobot280Socket

mc = MyCobot280Socket("UNO_Q_IP", 9000, timeout=1.0)
print(mc.get_angles())
```

After read-only verification succeeds, run a low-speed movement:

```python
from pymycobot import MyCobot280Socket

mc = MyCobot280Socket("UNO_Q_IP", 9000, timeout=1.0)
mc.send_angles([0, 0, 0, 0, 0, 0], 30)
```

Replace `UNO_Q_IP` with the actual UNO Q IP address, for example `192.168.1.218`.

## Network Safety

Use this mode only on a trusted LAN. Do not expose port `9000` to the public internet. Use one client at a time; multiple clients sending commands simultaneously can cause unpredictable robot movement.
