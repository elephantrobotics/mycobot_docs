# Chapter 7 UNO Q Development Board User Guide

Arduino UNO Q combines an MPU running Debian Linux with an MCU running Arduino sketches. With myCobot 280, UNO Q provides App Lab projects, local Python control on UNO Q, and LAN-based TCP remote control through the Bridge communication path.
