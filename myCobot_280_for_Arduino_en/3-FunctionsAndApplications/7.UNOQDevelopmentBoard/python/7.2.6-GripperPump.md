# 7.2.6 Gripper and Pump Control

Accessories should be connected according to their own wiring instructions before running these examples.

## Gripper

```python
import time
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)

mc.set_gripper_state(0, 50)  # open
time.sleep(2)
mc.set_gripper_state(1, 50)  # close
time.sleep(2)
mc.gripper_stop()
```

## Pump

```python
import time
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)

pump_pin = 2
mc.set_basic_output(pump_pin, 1)
time.sleep(2)
mc.set_basic_output(pump_pin, 0)
```

The exact IO pin depends on the accessory wiring. If the accessory does not respond, check the power supply, IO pin, and wiring polarity first.
