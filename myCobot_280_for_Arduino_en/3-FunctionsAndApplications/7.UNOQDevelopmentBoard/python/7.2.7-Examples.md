# 7.2.7 Integrated Examples

Run examples in the following order: RGB, home position, single joint, multiple joints, accessory control, and then integrated motion.

## Safe Demo Sequence

```python
import time
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)

mc.set_color(0, 255, 0)
time.sleep(1)

mc.send_angles([0, 0, 0, 0, 0, 0], 30)
time.sleep(3)

poses = [
    [0, -20, -40, 0, 30, 0],
    [20, -10, -30, 10, 20, 0],
    [-20, -10, -30, -10, 20, 0],
]

for pose in poses:
    mc.send_angles(pose, 30)
    time.sleep(3)

mc.send_angles([0, 0, 0, 0, 0, 0], 30)
mc.set_color(0, 0, 255)
```

If any step behaves unexpectedly, stop the program and return to the read-only checks before continuing.
