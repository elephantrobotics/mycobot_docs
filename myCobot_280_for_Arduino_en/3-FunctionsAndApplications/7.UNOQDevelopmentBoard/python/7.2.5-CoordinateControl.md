# 7.2.5 Coordinate Control

Coordinate control moves the end effector in Cartesian space. Use it only after joint control has been verified.

## Read Coordinates

```python
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)
print(mc.get_coords())
```

## Move to Coordinates

```python
import time
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)

coords = [160, 0, 220, 0, 0, 0]
mc.send_coords(coords, 30, 0)
time.sleep(3)
print(mc.get_coords())
```

## Jog Coordinates

```python
import time
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)

mc.jog_coord(1, 1, 30)  # X positive
time_to_move = 1
time.sleep(time_to_move)
mc.stop()
```

If inverse kinematics has no solution, use a smaller coordinate change or return to a known safe pose first.
