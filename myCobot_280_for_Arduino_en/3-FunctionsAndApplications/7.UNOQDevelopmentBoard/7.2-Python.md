# 7.2 Python Development

UNO Q supports Python programs running directly in the UNO Q Debian or App Lab environment. In this mode, `pymycobot` communicates with the firmware through the UNO Q Bridge path instead of opening a traditional serial port.

Use this section when the Python program runs on UNO Q itself. If the Python program runs on a PC and controls UNO Q over the network, use [7.3 TCP Socket Remote Control](7.3-TCPSocket.md).

## Basic Initialization

```python
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)
print(mc.get_angles())
```

When `unoq_bridge=True` is used, the library does not access `/dev/mycobot`. The UNO Q Bridge forwards myCobot protocol frames internally through `XferBridgeMsg`.
