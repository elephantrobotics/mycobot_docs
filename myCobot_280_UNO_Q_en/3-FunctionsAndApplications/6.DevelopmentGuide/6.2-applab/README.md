# 6.2 Development and Usage with Arduino App Lab

This section explains how to use **Arduino App Lab** with the UNO Q to open, run, and modify myCobot 280 examples.

## Scope

- **Audience**: First-time users and anyone who prefers running examples in the App Lab UI.
- **Recommended path**: Follow [6.2.1](./6.2.1-GettingStarted.md) for PC-hosted setup and RGB verification; use SBC mode for joystick control in [6.2.2](./6.2.2-Joystick.md).
- **Relation to Python**: Onboard Debian scripts, TCP Socket, APIs, and terminal joystick source are in [6.1 Development and Usage with Python](../6.1-python/README.md). This section does not cover terminal-only development.
- **Example entry**: Open myCobot **Built-in Case** apps on the App Lab **Apps** page, or import a complete App ZIP. An app typically includes `app.yaml`, `python/main.py`, `requirements.txt`, and a UNO Q–adapted `pymycobot` wheel (`sketch/` is not required in the current delivery).

Only one program may control the arm at a time. Click **Stop** before switching examples.
