# App Lab SBC Joystick Control

This section explains how to control myCobot 280 with a USB joystick in **Arduino App Lab (SBC mode)**. Joystick input moves the arm directly; run a mapping test before first use.

For Debian terminal usage, mapping-test source, and the full control script, see [6.1.8 Joystick Control (Debian Terminal and Source)](../6.1-python/6.1.8-Joystick.md).

## 1. Before You Begin

1. Connect a monitor, keyboard, mouse, and an externally powered USB Hub as described in [6.2.1 SBC mode](./6.2.1-GettingStarted.md#7-sbc-mode-optional).
2. Plug the joystick USB receiver into the Hub and confirm pairing. Do not plug or unplug the receiver while the arm is moving.
3. In App Lab, open the complete `Robot Handle Control` app (built-in case or imported ZIP). Keep `app.yaml`, `python/`, and the local `pymycobot` wheel (no `sketch/` required).
4. Ensure `python/requirements.txt` includes `pygame==2.6.1`. Stop other control programs before starting.
5. Secure the base and clear the workspace. Do not press gripper or pump buttons if those end-effectors are not installed.

## 2. Confirm Joystick Mapping First

Run the `Joystick Mapping Test` example first. It does not connect to or move the arm; App Lab Console only shows the device name and events such as `button 0 down`, `axis 3 value 1.000`, or `hat 0 value (1, 0)`.

On the verified bundled controller: A/B/X/Y → `button 0/1/2/3`, L1/R1 → `button 4/5`, L2/R2 → `axis 2/5`, left stick `axis 0/1`, right stick `axis 3/4`, D-pad `hat 0`. Always trust the mapping-test output for your device.

## 3. Control Functions

### 3.1 Arm Motion

| Control | Direction | `pygame` event | Function |
| --- | --- | --- | --- |
| Left stick | Up | `axis 1 < -0.3` | +X: `jog_coord(1, 1, 50)` |
| Left stick | Down | `axis 1 > 0.3` | −X: `jog_coord(1, 0, 50)` |
| Left stick | Left | `axis 0 < -0.3` | +Y: `jog_coord(2, 1, 50)` |
| Left stick | Right | `axis 0 > 0.3` | −Y: `jog_coord(2, 0, 50)` |
| Right stick | Up | `axis 4 < -0.3` | −Z: `jog_coord(3, 0, 50)` |
| Right stick | Down | `axis 4 > 0.3` | +Z: `jog_coord(3, 1, 50)` |
| Right stick | Left | `axis 3 < -0.3` | −RZ: `jog_coord(6, 0, 50)` |
| Right stick | Right | `axis 3 > 0.3` | +RZ: `jog_coord(6, 1, 50)` |
| D-pad | Up | `hat 0 (0, 1)` | +RX: `jog_coord(4, 1, 50)` |
| D-pad | Down | `hat 0 (0, -1)` | −RX: `jog_coord(4, 0, 50)` |
| D-pad | Left | `hat 0 (-1, 0)` | +RY: `jog_coord(5, 1, 50)` |
| D-pad | Right | `hat 0 (1, 0)` | −RY: `jog_coord(5, 0, 50)` |

All stick/D-pad motions are jog steps. If direction feels wrong, stop and re-check mapping numbers.

### 3.2 End Effector, Poses, and Servos

| Button | `pygame` event | Function | Condition |
| --- | --- | --- | --- |
| A | `button 0` | Pump on | Pump installed and plumbed |
| B | `button 1` | Pump off / release | Pump installed |
| X | `button 2` | Open gripper | Adaptive gripper installed |
| Y | `button 3` | Close gripper | Adaptive gripper installed |
| L1 | `button 4` | Zero pose | Enough clearance |
| R1 | `button 5` | Initial pose `[0, 0, -90, 0, 0, 0]` | Recommended after start |
| L2 | `axis 2 > 0.3` | Release all servos | See safety warning |
| R2 | `axis 5 > 0.3` | Power servos / lock joints | After L2 |

> **Safety warning:** L2 releases all servos; the arm may drop immediately. Support the arm before pressing L2 and keep clear of joints and the end effector. Use R2 to restore holding torque. Do not press R2 while the arm is jammed or forced.

## 4. Run and Stop in App Lab

1. In SBC mode, open App Lab, select the UNO Q, and open the complete `Robot Handle Control` app.
2. Click **Run**. In **Main / Python** Console, confirm a “joystick detected” (or equivalent) message. If none is found, the example retries about every 2 seconds.
3. Press R1 first for the initial pose, then small stick jogs, then end-effector buttons.
4. Click **Stop** to end. Wait until the arm is still before closing the app or unplugging the receiver.

Valid actions log API calls; centering sticks/D-pad sends `stop()`. On disconnect, the example stops the arm and waits to reconnect.

Mapping-test / control source and non–App Lab terminal usage: [6.1.8](../6.1-python/6.1.8-Joystick.md).

## 5. FAQ

| Symptom | What to check |
| --- | --- |
| Console does not detect joystick | Receiver, pairing, powered Hub, `pygame`; run mapping test first |
| Wrong direction or dead buttons | Stop immediately; compare mapping-test `axis` / `button` / `hat` |
| Pump or gripper does nothing | End effector installed and wired; do not press A/B/X/Y if missing |
| Arm does not respond | Stop other control entries; check power, wiring, and Console |
| Need terminal or source edits | See [6.1.8](../6.1-python/6.1.8-Joystick.md) |
