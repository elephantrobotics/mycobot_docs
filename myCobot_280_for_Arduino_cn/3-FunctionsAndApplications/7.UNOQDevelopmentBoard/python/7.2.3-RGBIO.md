# 7.2.3 RGB 与 IO 控制

## 1. RGB 灯测试

RGB 测试不会移动机械臂，适合作为首个控制案例：

```python
import time
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)
time.sleep(2)

for color in ((0, 0, 255), (255, 0, 0), (0, 255, 0)):
    mc.set_color(*color)
    time.sleep(2)
```

`set_color(r, g, b)` 的三个参数分别表示红、绿、蓝分量，范围为 `0`–`255`。

## 2. 数字输出

数字输出可用于经过确认的外设控制：

```python
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)
mc.set_digital_output(33, 0)
```

使用 IO 前必须核对外设型号、引脚和有效电平。不同配件的接线和控制逻辑可能不同，不要在未知接线下反复切换输出。
