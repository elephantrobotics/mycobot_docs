# 7.2.5 坐标控制

坐标数组格式为 `[X, Y, Z, RX, RY, RZ]`。建议先读取当前位置，再在安全范围内做小幅调整。

## 1. 读取当前坐标

```python
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)
coords = mc.get_coords()
print(coords)
```

如果返回空列表或错误帧，应先排查通信，不要继续发送坐标运动。

## 2. 发送完整坐标

```python
import time
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)
coords = mc.get_coords()
if len(coords) != 6:
    raise RuntimeError("未读取到有效坐标")

# 示例：在当前位置基础上将 Z 轴提高 10 mm
target = coords[:]
target[2] += 10
mc.send_coords(target, 20, 1)
time.sleep(3)
```

`send_coords(coords, speed, mode)` 的 `mode=0` 表示角度路径，`mode=1` 表示线性路径。运动前应确认目标位姿可达，并避免机械臂与桌面、底座或外设碰撞。

## 3. 坐标点动

```python
# X 正方向点动，速度 20
mc.jog_coord(1, 1, 20)

# 停止点动
mc.stop()
```

坐标轴编号为 `1`–`6`，依次对应 X、Y、Z、RX、RY、RZ。点动控制必须提供可靠的停止操作。
