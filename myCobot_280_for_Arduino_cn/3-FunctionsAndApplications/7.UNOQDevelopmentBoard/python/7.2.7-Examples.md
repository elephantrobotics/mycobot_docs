# 7.2.7 综合演示案例

板端示例目录提供以下脚本：

| 脚本 | 功能 | 是否产生运动 |
| --- | --- | --- |
| `control_rgb_demo.py` | RGB 颜色循环 | 否 |
| `go_home_demo.py` | 机械臂回零 | 是 |
| `single_joint_angle_demo.py` | 单关节运动 | 是 |
| `multi_joint_angles_demo.py` | 多关节运动 | 是 |
| `control_robot_sway_demo.py` | 左右摆动 | 是 |
| `control_robot_dance_demo.py` | 舞蹈动作 | 是 |
| `control_robot_gripper_demo.py` | 自适应夹爪测试 | 是 |
| `control_robot_pump_demo.py` | 吸泵搬运流程 | 是 |

## 1. 推荐运行顺序

```bash
cd ~/mycobot/example/
python3 control_rgb_demo.py
python3 go_home_demo.py
python3 single_joint_angle_demo.py
python3 multi_joint_angles_demo.py
```

每次只运行一个脚本。上一个脚本未退出时，不要启动下一个案例。

## 2. 左右摆动

左右摆动案例先回零，再让关节 1 到达指定位置，并循环控制关节 2：

```python
mc.send_angles([0, 0, 0, 0, 0, 0], 50)
time.sleep(2.5)
mc.send_angle(1, 90, 50)
time.sleep(2)

for _ in range(5):
    mc.send_angle(2, 50, 50)
    time.sleep(1.5)
    mc.send_angle(2, -50, 50)
    time.sleep(1.5)
```

## 3. 舞蹈和外设案例

舞蹈案例包含快速、连续的多姿态运动，需要充分清空工作区域。夹爪和吸泵案例还要求配件型号与接线符合案例说明。首次使用时应先阅读脚本中的目标角度、速度、等待时间和 IO 定义，再决定是否运行。

手柄案例需要额外的输入设备和驱动，参见 [7.6 SBC 手柄控制](../7.4-Joystick.md)。
