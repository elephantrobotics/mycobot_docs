# 7.2.2 API 使用说明

UNO Q 使用的机械臂控制方法与 `MyCobot280` API 保持一致，主要区别是对象初始化方式。

```python
from pymycobot import MyCobot280

# UNO Q 板端 Bridge 模式
mc = MyCobot280(unoq_bridge=True)
```

## 1. 常用 API 分组

为避免 GitBook 转 PDF 时表格内容被压缩，本节按功能分组列出常用方法。完整参数、取值范围和返回值请参见[第六章 Python API 说明](../../6.developmentGuide/python/7.2_API.md)。

### 状态读取

- `get_system_version()`：读取机械臂系统版本。
- `get_angles()`：读取 6 个关节当前角度。
- `get_coords()`：读取当前末端坐标。

### 关节运动

- `send_angle(id, degree, speed)`：控制单个关节运动到指定角度。
- `send_angles(angles, speed)`：控制多个关节运动到指定角度。
- `go_home()`：控制机械臂回到零位或初始姿态。

### 坐标运动

- `send_coord(id, coord, speed)`：控制单个坐标轴运动。
- `send_coords(coords, speed, mode)`：控制完整位姿运动。

### 点动控制

- `jog_angle(joint_id, direction, speed)`：按关节连续点动。
- `jog_coord(coord_id, direction, speed)`：按坐标轴连续点动。
- `stop()`：停止当前运动。

### 状态控制

- `pause()`：暂停当前运动。
- `resume()`：恢复运动。
- `power_on()`：上电或使能通信。
- `release_all_servos()`：释放全部舵机。

> 注意：释放舵机后机械臂可能失去保持力。请先扶稳机械臂，并确保其处于安全姿态。

### RGB 与 IO

- `set_color(r, g, b)`：控制末端 RGB 灯。
- `set_digital_output(pin_no, pin_signal)`：设置末端数字输出。
- `set_basic_output(pin_no, pin_signal)`：设置底部 IO 输出。

### 夹爪

- `set_gripper_state(flag, speed)`：控制夹爪打开或闭合。
- `set_gripper_value(gripper_value, speed)`：控制夹爪到指定开合值。
- `get_gripper_value()`：读取夹爪当前开合值。

## 2. UNO Q 使用注意事项

第六章中的串口初始化代码不能直接照搬到 UNO Q。UNO Q 板端 Python 创建对象时应使用：

```python
mc = MyCobot280(unoq_bridge=True)
```

调用运动 API 后，机械臂到位需要时间。简单示例可使用 `time.sleep()` 等待；需要严格判断时可配合 `is_in_position()`，并设置超时，避免程序无限等待。
