# 7.2.2 API 使用说明

UNO Q 使用的机械臂控制方法与 `MyCobot280` API 保持一致，主要区别是对象初始化方式。

```python
from pymycobot import MyCobot280

# UNO Q 板端 Bridge 模式
mc = MyCobot280(unoq_bridge=True)
```

常用方法如下：

| 类别 | 常用方法 | 作用 |
| --- | --- | --- |
| 状态读取 | `get_system_version()`、`get_angles()`、`get_coords()` | 读取版本、关节角度和坐标 |
| 关节运动 | `send_angle()`、`send_angles()`、`go_home()` | 控制单关节、多关节或回零 |
| 坐标运动 | `send_coord()`、`send_coords()` | 控制单个坐标轴或完整位姿 |
| 点动控制 | `jog_angle()`、`jog_coord()`、`stop()` | 连续点动与停止 |
| 状态控制 | `pause()`、`resume()`、`power_on()`、`release_all_servos()` | 暂停、恢复、上电和释放舵机 |
| RGB 与 IO | `set_color()`、`set_digital_output()` | 控制末端灯和数字输出 |
| 夹爪 | `set_gripper_state()`、`set_gripper_value()`、`get_gripper_value()` | 控制和读取夹爪 |

方法参数、取值范围和返回值请参见[第六章 Python API 说明](../../6.developmentGuide/python/7.2_API.md)。第六章中的串口初始化代码不能直接照搬到 UNO Q；创建对象时应改用 `MyCobot280(unoq_bridge=True)`。

调用运动 API 后，机械臂到位需要时间。简单示例可使用 `time.sleep()` 等待；需要严格判断时可配合 `is_in_position()`，并设置超时，避免程序无限等待。
