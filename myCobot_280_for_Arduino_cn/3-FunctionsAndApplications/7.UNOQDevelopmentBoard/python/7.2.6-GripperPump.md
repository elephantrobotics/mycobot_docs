# 7.2.6 夹爪与吸泵控制

只有在对应配件已经安装、接线正确且工作区域安全时，才能运行本节示例。

## 1. 自适应夹爪

```python
import time
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)
time.sleep(2)

# 张开夹爪
mc.set_gripper_state(0, 80, 1)
time.sleep(3)

# 闭合夹爪
mc.set_gripper_state(1, 80, 1)
time.sleep(3)

print("夹爪当前位置：", mc.get_gripper_value())
```

也可以使用 `set_gripper_value(value, speed, gripper_type)` 指定目标开合值。不要在夹爪中有人手或易损物品时测试闭合。

## 2. 吸泵

当前案例使用数字输出 `33` 控制吸泵，使用 `23` 控制泄气阀。运行前必须核对实际接线：

```python
import time
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)

def pump_on():
    mc.set_digital_output(33, 0)
    time.sleep(0.05)

def pump_off():
    mc.set_digital_output(33, 1)
    time.sleep(0.05)
    mc.set_digital_output(23, 0)
    time.sleep(1)
    mc.set_digital_output(23, 1)

pump_on()
time.sleep(2)
pump_off()
```

如果外设型号或接线与案例不同，应先按配件文档确认 IO 和有效电平，不能直接套用引脚编号。
