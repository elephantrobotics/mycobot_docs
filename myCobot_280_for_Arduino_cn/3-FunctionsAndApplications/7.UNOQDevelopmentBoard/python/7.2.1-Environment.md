# 7.2.1 环境与通信检查

## 1. 检查板端环境

打开 UNO Q 的 Debian 终端，执行：

```bash
uname -r
python3 --version
python3 -m pip --version
python3 -c "import importlib.metadata as m; print(m.version('pymycobot'))"
```

确认系统能够输出内核、Python、`pip` 和 `pymycobot` 版本。新板子可能还没有安装 `pip`，如果提示 `No module named pip`，需要先安装：

```bash
sudo apt update
sudo apt install -y python3-pip
python3 -m pip --version
```

已交付系统通常预装 UNO Q 适配版本的 `pymycobot`；如果包不存在，应取得与当前系统和项目匹配的安装包，不要直接用其他版本覆盖。

## 2. 初始化方式

```python
from pymycobot import MyCobot280

mc = MyCobot280(unoq_bridge=True)
```

UNO Q 的初始化与普通 PC 串口方式不同：

- 必须使用 `unoq_bridge=True`。
- 不填写串口设备名和波特率参数。
- Bridge 内部按 `1000000` 与机械臂通信，普通用户无需修改。

## 3. 只读通信测试

先读取版本和角度，不要立即发送运动命令：

```bash
python3 -c "from pymycobot import MyCobot280; mc = MyCobot280(unoq_bridge=True); print('version:', mc.get_system_version()); print('angles:', mc.get_angles())"
```

正常情况下会返回机械臂系统版本和 6 个关节角度。如果返回超时或残包，请停止其他控制程序，检查机械臂供电、D0/D1 接线，并参见[故障排查](../7.5-Troubleshooting.md)。

## 4. 运行脚本

将示例复制到 UNO Q 后，在脚本所在目录执行：

```bash
python3 your_demo.py
```

如果示例已按项目推荐目录部署，可执行：

```bash
cd ~/mycobot/example/debian
python3 control_rgb_demo.py
```

实际路径以设备上的部署位置为准。
