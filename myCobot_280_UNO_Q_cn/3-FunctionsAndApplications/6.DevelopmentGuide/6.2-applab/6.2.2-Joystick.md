# App Lab SBC 手柄控制

本节说明在 **Arduino App Lab（SBC 模式）** 下用 USB 手柄控制 myCobot 280。手柄会直接产生运动，首次使用请先做映射测试。

Debian 终端运行方式、映射测试源码与完整控制脚本见 [6.1.8 手柄控制（Debian 终端与源码）](../6.1-python/6.1.8-Joystick.md)。

## 1. 使用前准备

1. 按 [6.2.1 SBC 模式](./6.2.1-GettingStarted.md#7-sbc-模式可选) 连接显示器、键盘、鼠标和带外部供电的 USB Hub。
2. 将手柄 USB 接收器接入 Hub，确认手柄已配对；机械臂运动时不要插拔接收器。
3. 在 App Lab 中导入完整 `Robot Handle Control.zip`，保留 `app.yaml`、`python/` 和本地 `pymycobot` wheel（无需 `sketch/`）。
4. `python/requirements.txt` 需包含 `pygame==2.6.1`。启动前停止其他控制程序。
5. 固定底座并清空工作区域；未安装夹爪或吸泵时，不要按对应外设键。

## 2. 先确认手柄映射

先运行 `Joystick Mapping Test` 案例。它不连接、不移动机械臂，只在 App Lab Console 显示手柄名称与事件，例如 `button 0 down`、`axis 3 value 1.000`、`hat 0 value (1, 0)`。

配套手柄在已验证环境中通常为：A/B/X/Y → `button 0/1/2/3`，L1/R1 → `button 4/5`，L2/R2 → `axis 2/5`，左摇杆 `axis 0/1`，右摇杆 `axis 3/4`，十字键 `hat 0`。以映射测试输出为准。

## 3. 控制功能

### 3.1 机械臂移动

| 控件 | 操作 | `pygame` 事件 | 功能 |
| --- | --- | --- | --- |
| 左摇杆 | 上 | `axis 1 < -0.3` | X 增加：`jog_coord(1, 1, 50)` |
| 左摇杆 | 下 | `axis 1 > 0.3` | X 减小：`jog_coord(1, 0, 50)` |
| 左摇杆 | 左 | `axis 0 < -0.3` | Y 增加：`jog_coord(2, 1, 50)` |
| 左摇杆 | 右 | `axis 0 > 0.3` | Y 减小：`jog_coord(2, 0, 50)` |
| 右摇杆 | 上 | `axis 4 < -0.3` | Z 减小：`jog_coord(3, 0, 50)` |
| 右摇杆 | 下 | `axis 4 > 0.3` | Z 增加：`jog_coord(3, 1, 50)` |
| 右摇杆 | 左 | `axis 3 < -0.3` | RZ 减小：`jog_coord(6, 0, 50)` |
| 右摇杆 | 右 | `axis 3 > 0.3` | RZ 增加：`jog_coord(6, 1, 50)` |
| 十字键 | 上 | `hat 0 (0, 1)` | RX 增加：`jog_coord(4, 1, 50)` |
| 十字键 | 下 | `hat 0 (0, -1)` | RX 减小：`jog_coord(4, 0, 50)` |
| 十字键 | 左 | `hat 0 (-1, 0)` | RY 增加：`jog_coord(5, 1, 50)` |
| 十字键 | 右 | `hat 0 (1, 0)` | RY 减小：`jog_coord(5, 0, 50)` |

均为点动；方向异常时先停手，用映射测试确认编号。

### 3.2 外设、姿态与舵机

| 按键 | `pygame` 事件 | 功能 | 使用条件 |
| --- | --- | --- | --- |
| A | `button 0` | 打开吸泵 | 已安装吸泵且气路、接线正确 |
| B | `button 1` | 关闭吸泵并泄压 | 已安装吸泵 |
| X | `button 2` | 打开夹爪 | 已安装自适应夹爪 |
| Y | `button 3` | 关闭夹爪 | 已安装自适应夹爪 |
| L1 | `button 4` | 回零姿态 | 确认运动空间足够 |
| R1 | `button 5` | 初始姿态 `[0, 0, -90, 0, 0, 0]` | 建议启动后先执行 |
| L2 | `axis 2 > 0.3` | 释放全部舵机 | 见下方安全警告 |
| R2 | `axis 5 > 0.3` | 舵机上电并锁定 | L2 后恢复保持力时使用 |

> **重要安全警告：** L2 会释放全部舵机，机械臂可能立即下垂。按下前必须托住或支撑机械臂；人员远离关节与末端。恢复保持力时用 R2，机械臂受阻或被外力拉扯时不要执行。

## 4. 在 App Lab 中运行与停止

1. SBC 模式下打开 App Lab，选择 UNO Q，导入完整 `Robot Handle Control.zip`。
2. 点击 **Run**；在 **Main / Python** Console 确认出现“检测到手柄”。未检测到时，案例约每 2 秒重试。
3. 建议先按 R1 进入初始姿态，再用摇杆小幅点动，最后测外设键。
4. 停止时点 **Stop**；机械臂停稳后再关 App 或拔接收器。

有效操作会打印动作与接口调用；摇杆/十字键回中会发送 `stop()`。手柄断开时案例会先停臂，再等待重连。

映射测试或控制逻辑的源码、以及不经 App Lab 的终端运行方式，见 [6.1.8](../6.1-python/6.1.8-Joystick.md)。

## 5. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| Console 未检测到手柄 | 检查接收器、配对、Hub 外部供电、`pygame`；先跑映射测试 |
| 方向不对或按键无动作 | 立即停手；对照映射测试的 `axis` / `button` / `hat` |
| 吸泵或夹爪无动作 | 确认外设已安装且接线正确；未安装时不要按 A/B/X/Y |
| 机械臂无响应 | 先 Stop 其他控制入口，再查供电、接线与 Console |
| 需要终端或改源码 | 见 [6.1.8 手柄控制（Debian 终端与源码）](../6.1-python/6.1.8-Joystick.md) |
